# office-pidit — post assets

Image assets for [@office.pidit](https://instagram.com/office.pidit), served over
GitHub Pages so Instagram's Content Publishing API can fetch them by URL.

1000 posts, 1080x1920, JPEG q92. Generated from a fixed background template with
[the generator in the main project](https://github.com/kvyas1402) — one immutable
background, one font, one size, fully validated layout.

Files are named `office_pidit_0001.jpg` .. `office_pidit_1000.jpg` and correspond
to the rows of `content_plan.xlsx` in the generator project.
